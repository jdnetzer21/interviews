# 04 - AI (~30 min)

AI use is **expected** here. We assess how you drive it and how critically you check it. Deliver in `solutions/<name>/04-ai/`.

## Task 1: Generate and verify
Using any AI assistant, produce a Python script that parses [`sample_data.csv`](sample_data.csv) and prints the average `latency_ms` per `service`.
Deliver: the script, plus `prompts.md` with the prompts you used (and the AI's first answer if you changed it).

## Task 2: Catch the AI's mistakes
[`ai_answer.md`](ai_answer.md) is an AI-generated answer to "Why would a synchronous FIFO lose data?". It contains **at least 3 inaccuracies or weak points**. Mark them up in `critique.md` and write a corrected version.

## Task 3: Written answers (`answers.md`)
1. Give an example where AI helped you most and one where it misled you. How did you notice?
2. How do you protect confidential code/data when using AI tools?
3. How would you validate AI-generated RTL before trusting it?
4. Write a good prompt for "review my pull request for CDC issues". What context would you include?
5. What are the limits of LLMs for hardware design today?
