# 07 - Log analysis (3 scenarios, ~20 min each)

For each scenario, read the README, analyze the log with any tools (grep/awk/python/etc.), and deliver in
`solutions/<name>/07-log-analysis/scenario-N/`:

- `findings.md`: root cause, evidence (quote log lines with line numbers), timeline, and recommended fix
- `commands.md`: exact commands/scripts you used to get there
- Optionally: a script that automates the detection

| Scenario | Folder |
|---|---|
| 1 | [scenario-1-hang](scenario-1-hang/) - a simulation/job that hangs |
| 2 | [scenario-2-errors](scenario-2-errors/) - intermittent service errors |
| 3 | [scenario-3-perf](scenario-3-perf/) - performance regression |
